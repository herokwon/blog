## Global Constraints

- Preserve explicit saving, revision conflicts, manual uncertain-creation
  inspection, original unedited Markdown, and existing payloads.
- Recovery remains new-post-only, one copy per site, 168-hour expiry, 500 ms
  debounce and 2000 ms maximum wait; storage failure produces one nonblocking
  notice without fallback storage.
- Modal confirmation alone restores; intentional dismissals discard. Browser
  exit/reload and teardown do not count as deliberate dismissal.
- Retain strict CSP, nonce propagation, Markdown/URL/transfer guards and
  authentication boundaries. No broad inline-style exception or general
  console-error suppression.
- Layout values and exact UI copy are authoritative in Content domain; tests
  assert them without duplicating a second design specification here.

## Review Focus

1. A queued recovery write recreates discarded content: cancel it and suppress
   navigation/teardown recording (Task 2).
2. Reload while a modal is open erases a copy: retain it unless explicitly
   dismissed (Task 1).
3. Creation succeeds but publication fails: clear the submitted new-post copy
   and retain the known saved draft (Task 2).
4. Mobile keyboard or wrapping controls hide the editor: keep controls reachable
   and body scrolling independent (Task 3).
5. Logout navigation looks successful while authentication remains usable:
   require actual Access evidence, with visible failure/retry (Task 5).
